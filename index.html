What this system does

RESQ-AI fuses satellite imagery, rainfall data, infrastructure data, and citizen reports (English, Urdu, Roman Urdu) into a single explainable priority score per zone — for authorized responders to act on.

This is an AI decision-support system. It estimates and recommends — it does not autonomously dispatch resources or guarantee outcomes. Every output should be confirmed by a human responder before action.

Zones below start with realistic demo data so the dashboard is fully populated immediately. Go to Select & Analyze to replace it with live data for any real location.
